# Definitions

**Encoder**
: Un module qui détermine le sens et la vitesse de rotation d'un moteur à l'aide de deux pins.

**UART (série)**
: Un port classique de 8 pins représenté en 8 bits.

**PWM**
: Un port dont les pins peuvent être configurés à certaines fréquences pour modifier leur tension et leur intensité individuelle.
